How Romanian numbers are built

1. Learn 1–19

These are the basic blocks: unu, doi, zece, unsprezece, doisprezece…

2. From 20 to 99
tens + și + unit

25 = douăzeci și cinci. Exact tens stop after the tens word: 50 = cincizeci.

3. Hundreds
number + sută/sute + remainder

100 = o sută; 200 = două sute; 550 = cinci sute cincizeci.

4. Thousands
number + mie/mii + remainder

1 000 = o mie; 2 000 = două mii; 2 550 = două mii cinci sute cincizeci.

5. Decimal comma
whole number + virgulă + decimal part

1,5 = unu virgulă cinci; 12,35 = doisprezece virgulă treizeci și cinci. Say initial zeros: 12,05 = doisprezece virgulă zero cinci.

Important

„Și” joins tens and units: 42 = patruzeci și doi. Do not add it automatically after sută or mie: 542 = cinci sute patruzeci și doi.
